# Data structures and algorithms in C

Programs I wrote for the Data Structures and Algorithms course (second year, first semester) at Kathmandu University, plus my semester project.

## Contents (`Dsa3rdSem/`)

- **Linked lists:** `singlelinked.c`, `linked.c`, `linked2.c`, `nodeswap_linkedlist.c`
- **Stack and queue:** `stack1.c`, `queue.c`
- **Trees and graphs:** `binarytree.c`, `BST.c`, `graph.c`
- **Sorting:** `insertionsort.c`, `selectionsort.c`, `quicksort.c`, `heapsort.c`
- **Searching:** `binarysearch.c`

## Semester project

Library management system using linked lists in C: `libraryManagementInC.c`, with versions in `Dsa3rdSem/` (`LibraryManagement_project.c`, and `Librarymanagementwithfilehandling.c`, which saves records to `library.txt`).

## Build

```
gcc Dsa3rdSem/quicksort.c -o quicksort
./quicksort
```
